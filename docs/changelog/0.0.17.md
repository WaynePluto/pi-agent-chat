# Pi Agent Chat 0.0.17

## Added

- The `@` picker now indexes project directories alongside files; directories are shown and
  inserted with a trailing slash. Referencing a directory passes only its path to the model
  with a hint to inspect it as needed (`ls`/`find`/`read`); directory contents are never
  attached automatically ([#5](https://github.com/WaynePluto/pi-agent-chat/issues/5)).

## Fixed

- Proxied plain-HTTP provider requests no longer hang after a tool call; the global dispatcher
  now tunnels HTTP origins with CONNECT, matching the Pi SDK fix.

## Dependencies

- Pi SDK (`@earendil-works/pi-ai` / `@earendil-works/pi-coding-agent`): 0.84.4 → 0.85.1.
- `undici`: 8.10.0 → 8.10.2.

## Internal

- The unbundled runtime set under `dist/node_modules/` ships new SDK dependencies
  (`@earendil-works/chord`, `standardwebhooks`, `@stablelib/base64`, `fast-sha256`).
- `httpIdleTimeoutMs` accepts string values (`"disabled"`, numeric strings), matching the CLI.
- The "project files" self-check covers directory indexing, directory validation and rejection
  of vendor/build paths; the webview smoke baseline adds directory-chip steps.
- Dev dependencies: `@types/node` 26.4.0 → 26.4.1, `sass` 1.103.1 → 1.104.0.
