# Pi Agent Chat 0.1.2-20261016

## 变更

- 会话中途切换模型时丢弃先前模型产生的 thinking 块，不再作为纯文本发给新模型。
- OpenAI GPT-6 模型（API key）会话中途切换思考等级时保留 prompt 缓存。

## 修复

- 恢复的会话保留会话期间激活的工具。
- 自动重试现在对网关错误「Unable to forward upstream stream」与「The service is temporarily unavailable」生效。
- 参数含非法 `\u` 转义（如 `\usepackage`）的工具调用不再在出错前的已解析字段上静默运行；畸形 JSON 现在校验失败，模型能看到自己发送的原始参数。
- 反复 codemode 超时不再累积存活的 QuickJS worker；跨会话最多同时允许两个存活 worker。

## 升级

- Pi SDK（`@earendil-works/pi-ai` / `@earendil-works/pi-coding-agent`）：1.2.0 → 1.3.0。
- `undici`：8.11.2 → 8.12.2。
- 开发依赖：`jsdom` 30.1.2 → 30.1.3。

## 内部

- 1.3.0 升级后的 SDK-MIRROR 比对：`agent-session.ts` 唯一变化是 resume 时的工具装载恢复；全部镜像入口（`_startRun`、`_omitRecoveryAttempt`、事件 emit、http-dispatcher、`isSyntheticPath`、内置扩展清单）未变。
