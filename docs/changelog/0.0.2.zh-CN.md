# Pi Agent Chat 0.0.2

## 新增

- **运行中只读预览其他会话**：运行期间无需切换运行时即可浏览其他会话的转录，并一键返回当前运行。
- **宿主侧全面本地化**：原生对话框、QuickPick 列表与状态提示均为中英双语（68+ 条文案），与 webview 界面保持一致，包含引用文件提示。
- 折叠卡片补齐无障碍属性，改善键盘与屏幕阅读器支持。

## 修复

- 会话历史中的 `/skill` 调用恢复为原始 `/skill:name` 命令形式，不再显示展开后的完整 skill 内容（会话列表与转录回放均生效）。
- 修复空会话进入会话列表后「新会话」按钮不可点击的问题。

## 开发

- `pnpm verify` 新增 webview DOM 快照冒烟测试。
- `pnpm-lock.yaml` 不再写入 tarball 镜像地址，由各环境 registry 自行解析。
