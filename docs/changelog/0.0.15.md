# Pi Agent Chat 0.0.15

## Added

- Editor-area chat tabs are no longer a singleton: sidebar, editor area and separate windows
  are three equal regions, and the editor area hosts any number of tabs, each remembering its
  own session across restarts.
- Each region's title menu has four fixed items: move to the other two regions, new session in
  the editor area, new session in a new window.
- Session list rows get icon actions: rename / open in editor area / open in new window /
  delete. Rows occupied by another surface say so and move the session over on click; running
  controllers keep running in the background.
- Wide-screen draggable three-column layout (sessions rail / chat column / resources rail):
  splitters resize rails, dragging below the minimum closes a rail, double-click resets to
  280px; open state and widths persist across reloads.
- New setting `piAgentChat.layout.wideModeMinWidth` (default 1200, floor 932).

## Changed

- Visual redesign: four semantic colors with running in theme blue; framed messages on both
  sides (anchor side + colored edge); three-state execution-process block; separators and drop
  shadows replaced by whitespace and surfaces; raised sidebars; scrollbars appear only while
  scrolling (no track, no stepper arrows); composer as a single box; theme-aware editor-tab
  icons; streaming caret only on the message actually streaming.
- Session list: the 2px edge marks "running" only; badges moved to the front of the metadata
  line; "open elsewhere" in neutral gray; editor-area and new-window headers show the workspace
  name instead of the session title.
- `piAgentChat.layout.contentMaxWidth`: upper bound removed (minimum stays 500).
- Wide resources rail opens fully expanded; the narrow overlay starts collapsed.

## Fixed

- Manual retry button is no longer lost when a request settles on a timeout error.
- Session-row action buttons no longer overlap the title text.
- Search bar and jump-to-latest button no longer let chat text shine through (opaque
  background).
- Narrow-screen session list button toggles back to the chat; session tree and search are
  reachable from the list; search is disabled on empty sessions.

## Removed

- Static design mock and the `scratch/` directory (now gitignored).
- `Pi` byline above agent messages; unused `_mixins.scss`.
- Startup memory key `piAgentChat.lastSession.editor` (each tab remembers its session in
  webview state).

## Dependencies

- Pi SDK (`@earendil-works/pi-ai` / `@earendil-works/pi-coding-agent`): 0.84.2 → 0.84.3.
- `marked`: 18.0.9 → 18.0.11.

## Internal

- SCSS source maps wired up for development builds (packaging unaffected).
- Self-checks and headless webview smoke extended: region bookkeeping, restore degradation,
  wide/narrow resource defaults, manifest wide-threshold floor, retry offer. Webview DOM
  snapshot baseline updated.
