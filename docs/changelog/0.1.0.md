# Pi Agent Chat 0.1.0

## Added

- The CLI's built-in extensions are now loaded: `codemode`, `tool-search` and `mcp`. They are
  enabled by default and can be disabled per user or project with `-builtin:<name>` in the
  shared `extensions` setting; MCP servers come from the shared `mcp.json` / `pi mcp`
  configuration, and `/mcp` reports its status as a transcript notice instead of opening a
  TUI screen.
- The default-tools picker in the settings menu gains `codemode`; its checked state reads the
  parsed `defaultTools` setting, so a hand-written `+codemode` entry shows up as checked too.
- Tool cards show the execution time of each call; answer bubbles show the response time in
  the hover footer. Both read the SDK-persisted `durationMs`, so live and replayed
  transcripts agree.
- Nested tool calls — a tool calling other tools through `ctx.executeTool()`, such as a
  codemode script using `bash` — render as read-only rows inside the calling tool's card,
  both live and in replay.
- Images in tool results (codemode-generated images, `read` on image files) are displayed as
  thumbnails in the tool card.
- The settings menu gains a `codemode` item: tool presentation mode (`on` / `only`) and the
  description budget (default 3000), written to the shared `settings.json`.
- Virtual models are labeled `virtual` in the quick model menu and the native model picker.

## Changed

- The bundled model catalog follows SDK 1.1.0.

## Dependencies

- Pi SDK (`@earendil-works/pi-ai` / `@earendil-works/pi-coding-agent`): 0.87.1 → 1.1.0.
- `undici`: 8.11.0 → 8.11.2.
- `marked`: 18.0.14 → 18.1.0.
- Dev dependencies: `@types/vscode` 1.99.0 → 1.99.1, `@types/node` 24.19.0 → 24.19.1,
  `jsdom` 30.1.1 → 30.1.2.

## Internal

- `runtimePackages` gains `pi-codemode`, `pi-mcp` and `quickjs-wasi` (the QuickJS sandbox
  engine behind codemode).
- The esbuild `sdkModuleUrlPlugin` now covers `pi-codemode`, backfilling a disk URL for its
  module-level `import.meta.url` so the QuickJS worker can be located; dev builds clear
  `dist/node_modules` first to prevent stale copies.
- Adapted the compaction queue to the SDK 0.99 `preflightResult` semantics: the failure path
  is reported via the catch branch instead of leaving the queue's await hanging.
- New self-check for built-in extension loading: registration, `hidden` flags, and the
  codemode worker / wasm assets on disk.
- Webview smoke tests gain five steps (durations, nested calls live and replayed, tool result
  images, virtual model labels); the snapshot baseline is updated.
