# Pi Agent Chat 0.0.9

## Added

- **Parallel subagents via the `subagent` tool (off by default)**: the main agent can
  dispatch several sub-sessions at once, each editing the workspace directly inside a
  declared path scope. Scopes are path prefixes (not globs), checked for overlap before
  launch and enforced at runtime by rejecting out-of-scope `edit`/`write` calls; the
  report names the denied paths so the main agent can finish the job itself. Enforcement
  lives in the operations layer — sub-sessions exclude the built-in `edit`/`write` and get
  same-name, same-schema versions injected via SDK factories as the single enforcement
  point — while the known gap (`bash` writes can't be intercepted) is stated in every
  report. Failures are reported per lane with files actually written, never rolled back.
  Extension-registered `subagent` tools are always shadowed by name. Settings (enable /
  max subagents / default model) live on the VS Code settings page; empty sessions rebuild
  on the spot so changes apply immediately, non-empty sessions pick them up on the next
  session construction. New-session placeholders explain the setup in both states. Each
  lane streams live progress into a card in the main transcript.

- **Custom provider entry for `models.json`**: a new entry row at the top of the provider
  list opens the shared `~/.pi/agent/models.json` — an empty file gets a fully commented
  template, an existing file gets a new provider template inserted at the top (as an
  unsaved, undoable edit), and a 🗑 button removes a whole provider entry via
  `jsonc-parser`, preserving comments and formatting. Saving reloads the model catalog and
  surfaces parse errors as transcript cards.

- **Extension rendering: `setStatus` / `setWidget`, errors, and tool details**:
  `ctx.ui.setStatus` and `setWidget` (previously swallowed by a no-op Proxy) now render as
  a dedicated status line and composer-adjacent widget blocks; extension handler errors
  surface as transcript `error` cards via `bindExtensions({ onError })`. Tool
  `AgentToolResult.details` are sanitized host-side and rendered as a collapsed generic
  tree for tools without dedicated cards. The resource panel now reliably lights up
  Context and Extensions actually used this session.

- **Transcript search (Ctrl+F)**: literal, case-insensitive matching over the visible
  message text, aligned with the TUI full-screen search semantics; highlights use the CSS
  Custom Highlight API without touching the DOM, so streaming re-renders and history
  replay are unaffected. Enter/Shift+Enter navigate, Esc closes; a header search button is
  added and folds into the overflow menu when the panel is narrow.

- **Startup restores the last displayed session**: instead of always opening the most
  recently modified file on disk, the window remembers which session you were viewing per
  workspace — including empty new sessions that have no on-disk trace. First run still
  falls back to the `pi --continue` behavior.

- **Message bubble collapse & copy, code block syntax highlighting**: only the latest
  message per role stays expanded; earlier long messages collapse into previews (short
  ones never collapse), judged by Markdown source length so headless snapshots match the
  screen. Manually toggled bubbles are remembered per transcript. Messages and code blocks
  get copy buttons routed through the host clipboard. Fenced code blocks are highlighted
  with highlight.js — a hand-picked language subset, declared languages only, colors
  mapped to VS Code theme variables, with caching for streaming re-renders.

- **Settings menu: default tools and model list refresh**: a `defaultTools` multi-select
  (aligned with `/scoped-models`) manages which built-in tools new sessions start with,
  writable at user scope (`~/.pi/agent/settings.json`) or workspace scope
  (`<cwd>/.pi/settings.json`, overriding the former); a manual model list refresh entry
  triggers `refresh({ force: true })` with a 15s timeout and reports results as transcript
  cards.

## Improved

- **Pi SDK upgraded to 0.84.2** (`@earendil-works/pi-ai` / `pi-coding-agent`).

- **All webview-originated notices go to the transcript, not toasts**: switching/creating
  sessions mid-run, deleting the current session, renaming a running lane, shell path
  validation and similar rejections now land as scoped status/error cards; retry success no
  longer spawns an orphaned work block, and `/export` no longer double-reports.

- **Extension session lifecycle wired up**: sub-sessions get their own services,
  reloading goes through `AgentSession.reload()`, and `commandContextActions`
  (`newSession` / `fork` / `switchSession` / `navigateTree` / `reload`) are implemented so
  extension commands actually work.

- **View state is a single union type** (`live` / `lane` / `replay`) with all derived
  state computed; reading position (expanded blocks, scroll) is remembered per transcript;
  settings menu entries use a consistent two-row layout.

## Fixed

- **Error messages unwrap the `cause` chain**: undici network failures no longer stop at
  `TypeError: fetch failed` — the root cause (DNS, TLS, proxy, timeout) is surfaced in
  transcript error cards.

- **Scoped model list refreshes after login/logout and `models.json` reload**: models of
  logged-out providers no longer linger in the quick menu, and newly logged-in providers'
  models appear immediately.

- **Idle notifications no longer open a phantom work block**: unscoped status/error
  notices land top-level when nothing is running, and six command-originated failure
  paths are explicitly scoped to stay top-level.

- **Interrupting the agent starts a new work block**: queued/interjecting user messages
  now close the previous run's work block once consumed, instead of letting subsequent
  thinking and tool cards backfill into it.

- **Ctrl+F no longer triggers the editor search while the view is focused**: search is
  dispatched through a proper extension keybinding (`piAgentChat.openSearch`) instead of a
  webview keydown handler.

- **Extension widget styling**: collapsed headers no longer pick up the primary-button
  blue background, and widget blocks get proper spacing; message bubbles no longer show
  extra vertical margins; flat buttons no longer flash blue squares on hover.

- **VSIX packaging**: pi extensions failed to load from a packaged VSIX — `dist/node_modules`
  now ships the full transitive closure (with versions resolved from the SDK's perspective),
  and `import.meta.url` is rebuilt per SDK module; a sandbox check recreates the published
  layout outside the repo to keep this pinned.
