# Pi Agent Chat 0.1.0

## 新增

- 装载 CLI 自带的内置扩展：`codemode`、`tool-search` 与 `mcp`。默认启用，可在共享 `extensions` 设置里用 `-builtin:<name>` 按用户或项目禁用；MCP 服务器来自共享的 `mcp.json` / `pi mcp` 配置，`/mcp` 在本插件中以 transcript 通知的形式汇报状态。
- 设置菜单的默认工具多选加入 `codemode`；勾选态改读解析后的 `defaultTools` 设置，手写的 `+codemode` 条目同样显示为勾选。
- 工具卡片显示每次调用的执行耗时，回答气泡在 hover footer 显示该次响应的生成耗时；两者都读 SDK 持久化的 `durationMs`，实时与回放一致。
- 嵌套工具调用——工具经 `ctx.executeTool()` 调用其他工具，如 codemode 脚本调 `bash`——渲染为调用方工具卡片内的只读行，实时与回放一致。
- 工具结果里的图片（codemode 生成的图、`read` 读图片文件）以缩略图显示在工具卡片里。
- 设置菜单新增 `codemode` 项：工具呈现模式（`on` / `only`）与描述预算（默认 3000），写入共享 `settings.json`。
- 虚拟模型在快捷模型菜单与原生选择器中带 `virtual` 标注。

## 变更

- 内置模型目录随 SDK 1.1.0 更新。

## 升级

- Pi SDK（`@earendil-works/pi-ai` / `@earendil-works/pi-coding-agent`）：0.87.1 → 1.1.0。
- `undici`：8.11.0 → 8.11.2。
- `marked`：18.0.14 → 18.1.0。
- 开发依赖：`@types/vscode` 1.99.0 → 1.99.1、`@types/node` 24.19.0 → 24.19.1、`jsdom` 30.1.1 → 30.1.2。

## 内部

- `runtimePackages` 新增 `pi-codemode`、`pi-mcp` 与 `quickjs-wasi`（codemode 的 QuickJS 沙箱引擎）。
- esbuild 的 `sdkModuleUrlPlugin` 覆盖 `pi-codemode`，为其模块级 `import.meta.url` 回填磁盘 URL 以定位 QuickJS worker；开发构建先清空 `dist/node_modules`，防止陈旧副本。
- 压缩队列适配 SDK 0.99 的 `preflightResult` 语义：失败路径经 catch 分支补报，不再悬挂队列的 await。
- 新增内置扩展装载自检：注册情况、`hidden` 标记与 codemode 的 worker / wasm 磁盘资产。
- webview 冒烟测试新增五步（耗时、嵌套调用的实时与回放、工具结果图片、虚拟模型标注），快照基线同步更新。
