# Pi Agent Chat 0.0.15

## 新增

- 编辑区会话 tab 不再是单例：侧边栏、编辑区、新窗口为三个对等区域，编辑区可开任意多个独立 tab，每个 tab 跨重启记住自己的会话。
- 每个区域标题菜单固定四项：移到另外两个区域、在编辑区新开会话、在新窗口新开会话。
- 会话列表行操作改为图标按钮：重命名 / 在编辑器区域打开 / 在新窗口打开 / 删除；被其他 surface 占用的行点击即把会话移入，运行中的 controller 转为后台继续。
- 宽屏可拖拽三栏布局（会话栏 / 聊天列 / 资源栏）：分隔线拖拽调宽，拖到最小宽度以下即关闭，双击重置回 280px；开合状态与宽度跨重载记忆。
- 新设置 `piAgentChat.layout.wideModeMinWidth`（默认 1200，下限 932）。

## 变更

- 视觉重做：语义色收为四个、运行中改主题蓝；双侧消息恢复消息框（锚定侧 + 彩色边）；执行过程三态；分隔改留白与面色、删除全部投影；侧栏改为抬起的面；滚动条仅在滚动时出现（无槽、无步进箭头）；composer 合为单框；编辑区 tab 图标跟随主题；流式光标只在正在流式的那条消息上。
- 会话列表：2px 边条只表「运行中」；徽章移到元信息行行首；「已在另一处打开」改中性灰；编辑区/新窗口 header 显示工作区名而非会话标题。
- `piAgentChat.layout.contentMaxWidth`：去掉上限（下限仍为 500）。
- 宽屏资源栏开即逐层全展开；窄屏浮层默认折叠。

## 修复

- 请求以超时错误落定时，手动重试按钮不再丢失。
- 会话行操作按钮不再压住标题文字。
- 搜索栏与跳到最新按钮改不透明底色，对话文字不再透出。
- 窄屏会话列表按钮可再次点击返回对话；列表可直达会话树与搜索；空会话禁用搜索。

## 移除

- 删除 design 静态视觉稿与 `scratch/` 目录（已加入 .gitignore）。
- 删除 agent 消息上方的 `Pi` byline 与无引用的 `_mixins.scss`。
- 移除启动记忆键 `piAgentChat.lastSession.editor`（各 tab 改用 webview state 记忆）。
