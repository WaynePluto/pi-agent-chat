# Pi Agent Chat 0.0.7

## Added

- **In-composer quick menus for model and thinking level**: the native QuickPick always
  opens at the top of the window, far from the chip you tapped. A new `webview/picker.ts`
  draws a small popover right above the composer chip for fast switching:
  - The model menu lists only frequently used (scoped) models — one name + provider per
    row — and shows "None" when none are configured; a trailing "Other models…" entry
    opens the full native picker (search, capability details, ⭐ frequently used, 📌
    default).
  - The thinking-level menu lists the levels the current model supports, with no "default"
    marker: the SDK's `setThinkingLevel()` writes the chosen level straight into
    `defaultThinkingLevel`.
  - `/model` (no argument) and `/thinking` now tell the webview to open the matching menu,
    and `ChatState.canSelectThinkingLevel` is replaced by `thinkingLevels`.

## Improved

- **Long session-tree node display**: indentation now increases only at real branch points
  with a capped maximum depth; node titles are limited to ten characters with the
  timestamp moved onto the title line, while the full message stays on the content line
  and remains searchable in the details view.

## Fixed

- **Context-compaction interaction**: resuming a session now replays the full branch and
  shows an expandable compaction boundary. During compaction the composer stays editable,
  queues incoming messages, and resumes them once compaction finishes. Manual and
  automatic compaction states are now aligned, with stop, undo, and bilingual prompts.
