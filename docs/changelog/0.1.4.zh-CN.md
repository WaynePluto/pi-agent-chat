# Pi Agent Chat 0.1.4

## 变更

- 模型目录更新到 models.dev v2，新增 OpenAI、Azure OpenAI Responses 与 OpenAI Codex 的 GPT-6.1 Terra；OpenAI 默认模型改为 `gpt-6.1-sol`。
- 大体积流式工具调用改为增量解析，不再每个增量重解析整段参数；已渲染代码复用先前的高亮结果。

## 修复

- `tool_search` 与 codemode 的 `searchTools()` 支持中文等非 ASCII 查询，此前对这类查询一无所获。
- 缩放后的图片附件不再在 JPEG 明显更小时仍以数 MB 的 PNG 发送，缩放改选更小的编码。
- SDK 会话的压缩与分支摘要不再把存储的 OAuth 令牌当作显式 API key 传回供应商。
- 会话写入失败不再把磁盘上不存在的条目留在内存里（此前会导致 resume 后丢失更早的历史）。
- Windows 路径改为大小写不敏感比较，修复工作目录与主目录仅盘符大小写不同时技能被加载两次、项目信任被反复询问的问题。
- glob 匹配对放大式模式的拒绝服务攻击做了加固；MCP OAuth 登录拒绝非 HTTP 的授权端点。

## 升级

- Pi SDK（`@earendil-works/pi-ai` / `@earendil-works/pi-coding-agent`）：1.4.0 → 1.5.0。
- `marked`：18.1.1 → 18.1.3。
- 开发依赖：`@vscode/vsce` 4.0.0 → 4.1.0，`sass` 1.106.1 → 1.107.1。

## 内部

- 随包发行清单新增 `@earendil-works/pi-schema`（SDK 1.5.0 拆出的新包）与 `@isaacs/nonrecursive-glob-match`（minimatch 11 的引擎）。
- 1.5.0 升级后的 SDK-MIRROR 比对：`http-dispatcher`、`builtInExtensions`、`isSyntheticPath`、自动重试两步、`/skill:` 前缀与 cli-runtime 全局均未变；`ExtensionUIContext` 成员清单除 `custom()` 上一个 TUI 专属的 `blocked` 选项外无变化。
