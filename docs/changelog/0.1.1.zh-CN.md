# Pi Agent Chat 0.1.1

## 变更

- 模型选择器（composer 快捷菜单、完整模型选择器、`/scoped-models`）与 composer 模型 chip 现在显示模型名称而非技术 id；规范的 `provider/modelId` 引用仍保留在 tooltip 中。
- 常用/默认模型的状态提示现在使用模型名称。

## 升级

- Pi SDK（`@earendil-works/pi-ai` / `@earendil-works/pi-coding-agent`）：1.1.0 → 1.2.0。
- `marked`：18.1.0 → 18.1.1。
- 开发依赖：`@types/node` 24.19.1 → 24.19.2。

## 内部

- webview 冒烟 fixtures 与快照基线覆盖模型显示名路径。
- 手动重试 / 继续改经 SDK 重构后的运行入口重发；SDK 1.2.0 升级后重试按钮照常可用。
- `dist/node_modules/` 运行时集合移除 `@earendil-works/chord`（上游 SDK 已删除该依赖）。
