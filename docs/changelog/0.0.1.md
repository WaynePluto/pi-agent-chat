# Pi Agent Chat 0.0.1

Initial public release of Pi Agent Chat, a VS Code sidebar UI for the Pi Coding Agent built on the official bundled SDK (no Pi CLI required).

## Added

- Bilingual English and Chinese sidebar chat UI.
- Streaming Markdown responses and tool execution cards.
- Session creation, listing, resume, delete, tree navigation, fork and clone.
- Model and thinking-level switching, authentication, abort and follow-up actions.
- Native VS Code diff and target-file views for edit results.
- Slash command completion for built-ins, prompts, extensions and skills.
- Project file references through the `@` composer search.
- Reuse of the terminal Pi configuration and sessions under `~/.pi/agent/`.
- Bundled Pi SDK runtime with platform-specific VSIX builds for Windows x64,
  Linux x64 and macOS arm64.
- GitHub Actions CI and tag-based GitHub Release packaging.
