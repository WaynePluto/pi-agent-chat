# Pi Agent Chat 0.0.17

## 新增

- `@` 选择器现在同时索引项目目录；目录以尾随斜杠展示与插入，引用目录时只向模型传递路径并提示按需检查（`ls`/`find`/`read`），不会自动附加目录内容（[#5](https://github.com/WaynePluto/pi-agent-chat/issues/5)）。

## 修复

- 经代理的 plain-HTTP 模型请求不再在工具调用后挂起；全局 dispatcher 改为以 CONNECT 隧道转发 HTTP 源，对齐 Pi SDK 修复。

## 升级

- Pi SDK（`@earendil-works/pi-ai` / `@earendil-works/pi-coding-agent`）：0.84.4 → 0.85.1。
- `undici`：8.10.0 → 8.10.2。

## 内部

- `dist/node_modules/` 非打包运行时集合新增 SDK 依赖（`@earendil-works/chord`、`standardwebhooks`、`@stablelib/base64`、`fast-sha256`）。
- `httpIdleTimeoutMs` 接受字符串取值（`"disabled"`、数字串），与 CLI 一致。
- 「project files」自检覆盖目录索引、目录校验与 vendor/build 路径拒绝；webview 冒烟基线新增目录 chip 步骤。
- 开发依赖：`@types/node` 26.4.0 → 26.4.1、`sass` 1.103.1 → 1.104.0。
