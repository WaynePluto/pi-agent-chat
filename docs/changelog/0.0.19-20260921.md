# Pi Agent Chat 0.0.19-20260921

## Dependencies

- Pi SDK (`@earendil-works/pi-ai` / `@earendil-works/pi-coding-agent`): 0.85.1 → 0.86.1.
- `marked`: 18.0.11 → 18.0.13.

## Internal

- jiti is no longer bundled into `dist/extension.js`; it loads at runtime from the shipped
  `dist/node_modules/` copy, as the SDK 0.86 extension loader requires.
- The `@mariozechner/clipboard` runtime package is dropped from the shipped set; the SDK's
  native clipboard now lives inside `@earendil-works/pi-tui`. The native-clipboard spike
  probe was removed with it.
- The unbundled runtime set tracks the SDK 0.86 dependency tree: adds `proxy-agent-negotiate`,
  drops nine AWS/Smithy transitive packages and `glob`.
- Dev dependencies: `@vscode/vsce` 3.9.2 → 4.0.0, `jsdom` 30.0.1 → 30.1.0, `sass` 1.104.0 →
  1.104.1, `@types/node` 24.13.3 → 24.13.6.
