# Pi Agent Chat 0.0.4

## Added

- **Skill activity visibility**: tool cards now distinguish loading a skill's `SKILL.md`
  from accessing one of its bundled resources. The resource panel highlights skills
  that were actually loaded in the current transcript.
- **Resource origins and file access**: skills, prompts, extensions and other
  resources are grouped by global, project, package or other origin. Resource rows
  that represent files can be opened directly in VS Code.

## Improved

- Session-tree navigation and forking restore selected persisted skill invocations
  to their concise `/skill:<name>` form instead of prefilling the composer with
  expanded skill instructions. Replayed transcripts retain skill attribution.
- The resource and composer panels manage their available space more consistently.
- Extension metadata now identifies the bundled Pi SDK version (`0.83.0`).

## Fixed

- `/reload` now posts a localized completion message after its resources have been
  refreshed.
