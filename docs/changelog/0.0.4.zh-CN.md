# Pi Agent Chat 0.0.4

## 新增

- **技能活动可见性**：工具卡片会区分读取技能的 `SKILL.md` 与访问其附带资源；资源面板会高亮当前转录中实际加载过的技能。
- **资源来源与文件访问**：技能、提示词、扩展及其他资源会按全局、项目、包或其他来源分组；代表文件的资源行可直接在 VS Code 中打开。

## 改进

- 在会话树中导航或分叉时，选中的已持久化技能调用会还原为简洁的 `/skill:<name>` 形式，不会再把展开的技能指令预填进输入框；转录回放会保留技能归属信息。
- 资源面板和输入面板会更一致地管理可用空间。
- 扩展元数据现在会标明内置 Pi SDK 版本（`0.83.0`）。

## 修复

- `/reload` 刷新资源后会显示本地化的完成提示。
