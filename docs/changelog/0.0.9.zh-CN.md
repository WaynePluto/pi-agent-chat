# Pi Agent Chat 0.0.9

## 新增

- **并行子代理 `subagent` 工具（默认关闭）**：主代理可一次派出多路子会话，各自在声明的路径范围内直接修改工作区。范围使用路径前缀（非 glob），启动前静态检查重叠，运行中越界的 `edit`/`write` 直接拒绝，汇报附被拒的具体路径供主代理自行收尾。强制落在 operations 层——子会话排除内置 `edit`/`write`，经 SDK 工厂注入同名同 schema 版本作为唯一强制点；已知缺口（`bash` 写文件无法拦截）在每份汇报中明写。失败逐路照实汇报并记账实际写过的文件，不做回滚。始终按名字屏蔽扩展注册的 `subagent`。设置项（开关 / 最大并行数 / 子代理默认模型）走 VS Code 设置页；空会话在配置变更后原地重建即时生效，非空会话在下一次会话构造时生效。新会话占位提示按开关两态给出说明。每一路的实时进展流入主会话 transcript 中的卡片。

- **自定义供应商入口（models.json）**：供应商列表首行新增入口，打开共享配置 `~/.pi/agent/models.json`——空文件写入带注释的整份模板，已有内容则向 `providers` 顶部插入一条新模板（存为未保存编辑，可撤销）；🗑 按钮经 `jsonc-parser` 删除整个 provider 条目，保留注释与格式。保存后重新加载模型目录，解析错误以 transcript 卡片显示。

- **扩展呈现：`setStatus` / `setWidget`、错误与工具 details**：`ctx.ui.setStatus` 与 `setWidget`（此前落在 no-op Proxy 里被静默吞掉）分别渲染为独立状态行与输入框上下文的 widget 块；扩展 handler 抛出的错误经 `bindExtensions({ onError })` 变成 transcript 的 `error` 卡片。工具 `AgentToolResult.details` 经宿主清洗后为没有专用卡片的工具画成默认折叠的通用树。资源面板稳定点亮本会话真正生效过的 Context 与 Extensions。

- **transcript 搜索（Ctrl+F）**：字面匹配、大小写不敏感，语料为消息区可见文本，对齐 TUI 全屏搜索语义；高亮走 CSS Custom Highlight API，不改 DOM，流式重渲染与历史回放互不干扰。Enter/Shift+Enter 前后导航，Esc 关闭；header 新增搜索按钮，面板过窄时自动收纳进溢出菜单。

- **启动时回到上次显示的会话**：不再固定打开「磁盘上最近修改的会话」，而是按工作区记住你最后查看的会话——包括磁盘上毫无痕迹的空新会话。首次运行仍保持 `pi --continue` 行为。

- **消息气泡折叠与复制、代码块语法高亮**：每个角色仅最新一条消息默认展开，更早的长消息折叠成预览（短消息永不折叠），是否够长按 Markdown 源文本判定，保证无头快照与屏幕一致；手动开合过的气泡按 transcript 记忆。消息与代码块新增复制按钮，写剪贴板走宿主通道。代码块用 highlight.js 高亮——手选语言子集、只高亮 fence 声明的语言、配色映射到 VS Code 主题变量，带缓存以承受流式重渲染。

- **设置菜单：默认工具与模型列表刷新**：新增 `defaultTools` 多选（对齐 `/scoped-models` 交互），管理新会话启动时启用的内置工具，支持用户作用域（`~/.pi/agent/settings.json`）与工作区作用域（`<cwd>/.pi/settings.json`，覆盖前者）；新增模型列表手动刷新入口，触发 `refresh({ force: true })`（15 秒超时），结果以状态/错误卡片落入 transcript。

## 改进

- **内置 Pi SDK 升级至 0.84.2**（`@earendil-works/pi-ai` / `pi-coding-agent`）。

- **webview 内触发的提示统一走 transcript 而非弹窗**：运行中切换/新建会话、删除当前会话、重命名运行中的子代理、shell 路径校验失败等拒绝提示改为带 scope 的 status/error 卡片；重试成功不再凭空开出孤立的执行块，`/export` 不再重复报成功。

- **扩展会话生命周期接线**：子会话使用独立的 services，重载统一走 `AgentSession.reload()`，实现 `commandContextActions`（`newSession` / `fork` / `switchSession` / `navigateTree` / `reload`），扩展命令真正可用。

- **视图状态收敛为单一联合类型**（`live` / `lane` / `replay`），派生状态全部计算得出；阅读位置（展开块、滚动）按 transcript 记忆；设置菜单入口项统一为两行排版。

## 修复

- **错误信息解包 `cause` 链**：undici 网络失败不再止步于 `TypeError: fetch failed`，真实原因（DNS、TLS、代理、超时）直接显示在 transcript 错误卡片中。

- **登出/登录与 models.json 重载后常用模型列表及时更新**：已登出供应商的模型不再滞留快捷菜单，新登录供应商的模型立即可见。

- **空闲时的通知不再凭空开出执行块**：未标 scope 的 status/error 通知在无运行时落顶层，六处命令来源的失败路径显式标 scope 保持顶层。

- **用户插话后开启新的执行过程**：排队/插话消息被消费后即结束上一轮执行块，后续思考与工具卡片不再回填进旧块。

- **视图聚焦时 Ctrl+F 不再同时触发编辑器搜索**：改经扩展键绑定分派到新命令 `piAgentChat.openSearch`，替代 webview 内部拦不住的 keydown。

- **扩展 widget 样式**：折叠头不再吃到主按钮蓝背景，widget 块间距修正；消息气泡上下多余间距修复；扁平按钮 hover 不再被基样式刷成蓝色方块。

- **VSIX 打包**：修复打包后 pi 扩展加载失败——`dist/node_modules` 补齐传递依赖闭包（版本按磁盘 SDK 的视角解析），`import.meta.url` 改为逐模块重建；新增沙箱校验在仓库外重建发布布局，钉住该回归。
