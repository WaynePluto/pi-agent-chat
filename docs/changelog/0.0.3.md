# Pi Agent Chat 0.0.3

## Added

- **Settings menu and shell-path configuration**: the header provider control is now a
  settings menu containing provider selection, shell-path configuration and command
  help. Common local shells can be detected and selected, custom paths can be entered,
  and the setting is shared with the Pi CLI through `~/.pi/agent/settings.json`.
- New `/shell-path` and `/help` commands. Command help is generated from the built-in
  command catalog and localized to VS Code's display language.
- **Session management improvements**: rename and delete actions have fixed positions
  in the session list; queued or interrupted messages can be recalled into the composer;
  and the header displays the current session's name.
- Newly started in-memory sessions now appear in the session list before the SDK has
  persisted them to disk.
- **Richer model selector**: models show supported input modalities, context window,
  maximum output and thinking capability. Entries are grouped by provider and can be
  searched by provider or capability.

## Improved

- **Much faster session-history replay**: transcript replay builds into a
  `DocumentFragment`, avoids per-event scrolling and reuses the empty-session
  placeholder. In jsdom, replaying 1,000 events improves from about 6.3 seconds to
  183 ms.
- Session changes and newly created sessions show a loading state immediately instead
  of briefly displaying the previous transcript. Replay now precedes extension binding
  and resource collection, while session-list refresh no longer blocks the transcript.
- Local command results (such as `/session` and `/copy`) are shown as expanded,
  top-level transcript cards rather than being folded into execution-process blocks.
- CSS now uses shared semantic variables and common collapsed, chevron, pulse and
  truncation rules, without changing the visual design.
- Added session loading and replay phase timing logs to help diagnose large sessions.

## Fixed

- Corrected excessive top spacing in queued and interrupted message bubbles when a
  badge precedes the first paragraph.
- Local command notifications no longer create execution-process blocks whose running
  animation never stops.
- Replaying a session that is still streaming no longer prematurely closes its active
  execution-process block.
- Refresh the session list when an agent run starts, and after the first assistant
  response for a new session completes.
