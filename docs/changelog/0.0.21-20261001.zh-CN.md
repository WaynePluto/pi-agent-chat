# Pi Agent Chat 0.0.21-20261001

## 新增

- 装载 CLI 自带的内置扩展：`codemode`、`tool-search` 与 `mcp`（SDK 0.99 起随包提供）。默认启用，可在共享 `extensions` 设置里用 `-builtin:<name>` 按用户或项目禁用；MCP 服务器来自共享的 `mcp.json` / `pi mcp` 配置，`/mcp` 在本插件中以 transcript 通知的形式汇报状态。
- 设置菜单的默认工具多选加入 `codemode`；勾选态改读解析后的 `defaultTools` 设置，手写的 `+codemode` 条目同样显示为勾选。

## 变更

- 内置模型目录随 SDK 0.99.2 更新，新增条目包括 OpenAI、Azure OpenAI 与 OpenAI Codex 的 GPT-6.1 Sol。

## 升级

- Pi SDK（`@earendil-works/pi-ai` / `@earendil-works/pi-coding-agent`）：0.87.1 → 0.99.2。
- `undici`：8.11.0 → 8.11.2。

## 内部

- `runtimePackages` 新增 `pi-codemode`、`pi-mcp` 与 `quickjs-wasi`（codemode 的 QuickJS 沙箱引擎）。
- esbuild 的 `sdkModuleUrlPlugin` 覆盖 `pi-codemode`，为其模块级 `import.meta.url` 回填磁盘 URL 以定位 QuickJS worker；开发构建先清空 `dist/node_modules`，防止陈旧副本。
- 压缩队列适配 SDK 0.99 的 `preflightResult` 语义：失败路径经 catch 分支补报，不再悬挂队列的 await。
- 新增内置扩展装载自检：注册情况、`hidden` 标记与 codemode 的 worker / wasm 磁盘资产。
- 开发依赖：`@types/vscode` 1.99.0 → 1.99.1。
