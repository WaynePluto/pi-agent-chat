# Pi Agent Chat 0.0.2

## Added

- **Read-only session preview**: while a run is in progress, browse other sessions'
  transcripts without touching the runtime session, and jump back to the live run
  with one click.
- **Full host-side localization**: native dialogs, QuickPick lists and status prompts
  are now bilingual English/Chinese (68+ messages), consistent with the webview UI —
  including the referenced-files header.
- Accessibility attributes for collapsible cards, improving keyboard and
  screen-reader support.

## Fixed

- `/skill` invocations in session history are restored to the original
  `/skill:name` command form instead of the expanded skill block — in both the
  session list and replayed transcripts.
- The "New Session" button was unclickable after entering the session list from
  an empty session.

## Development

- Webview DOM snapshot smoke test added to `pnpm verify`.
- `pnpm-lock.yaml` no longer bakes in tarball mirror URLs; each environment
  resolves its own registry.
