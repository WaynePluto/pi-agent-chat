# Pi Agent Chat 0.0.10

## 变更

- **搜索覆盖折叠内容**：transcript 搜索不再止步于折叠边界。折叠的工作块与被折叠的长消息中的文本直接参与匹配（其文本仍在 DOM 中）；从未渲染过的卡片 body——工具参数与输出、思考文本、通知、压缩摘要、`details` 载荷——则经数据层文本搜索（折叠卡片的 body 在首次展开前根本不在 DOM 里）。

- **命中折叠区域时层层展开**：定位到隐藏匹配会先打开工作块、再展开卡片（同时渲染其 body），随后重建搜索语料并重新落在卡片内第一个可见匹配上；卡片内嵌套的 details 折叠块在此过程中完成登记，因此再按一次 Enter 会继续展开那一层。被折叠的消息气泡同理展开。匹配按文档位置排序，上一个/下一个始终自上而下。

- **搜索框样式对齐 VS Code 查找控件**：匹配计数移入输入框内部（输入的文字不会与计数重叠），上一个/下一个/关闭三键改为 22×22 平面图标按钮，使用官方 `codicon` 字形（`arrow-up`、`arrow-down`、`close`）逐字内嵌为本地 SVG 路径——不引字体、不用任何网络资源。

## 移除

- **Ctrl+F 键绑定与 `piAgentChat.openSearch` 命令**：webview 的 keydown 会被工作台键绑定服务先于页面 `preventDefault()` 转发，该键绑定无法在所有焦点状态下稳定压过默认的编辑器查找——Ctrl+F 有时打开的是编辑器搜索而不是会话搜索。现在搜索仅由 header 的搜索按钮触发，Ctrl+F 完全回归 VS Code 默认行为，与本插件零竞争。

## 内部

- transcript 搜索新增双层语料（DOM 文本 + 经 `collectHiddenBodies()` 获取的未渲染懒加载 body）与展开注册表（`revealTranscriptElement()`），均位于 `webview/transcript.ts`；新增无头测试场景，断言命中「从未渲染过的折叠卡片」内部时 Enter 会展开工作块并渲染卡片 body。
