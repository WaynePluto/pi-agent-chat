# Pi Agent Chat 0.0.5

## 新增

- **消息级会话树操作**：悬停用户消息时，可直接显示回到这里、分叉会话和添加标签操作。回到这里会把原始提示词恢复到输入框，方便重试或换模型重发。
- **自适应操作收纳**：侧边栏宽度不足时，header 与输入框的次要操作会移入更多菜单；状态行无法完整显示时会整行隐藏。
- **模型设置与会话导出**：模型选择器会将常用模型置顶，并提供行内 `⭐` 操作切换常用状态、`📌` 操作设置默认模型，且默认模型与当前会话的模型选择相互独立。`/scoped-models` 仍可用于批量管理并保持 CLI 兼容；共享设置菜单可直接打开配置文件。会话导出现在默认生成 HTML，同时保留 JSONL 导出。

## 改进

- **会话列表性能**：仅在会话页可见时扫描会话文件，并合并密集的刷新请求；标题搜索与滚动分批渲染让大型会话列表保持流畅。
- 技能高亮或资源刷新重建资源面板后，各资源分区仍会保持原有的展开状态。
- 使用编辑器背景区分聊天区域，助手消息采用输入区背景，增强视觉层次。
- VSIX 打包与安装现已拆分：可按需使用 `pnpm package:vsix`、`pnpm install:vsix` 或 `pnpm package-and-install:vsix`。

## 修复

- 不支持选择思考等级的模型不再在输入区显示思考等级按钮。
- 排队消息的状态徽标不会再把短文本挤压成逐字换行。
- 用户消息悬停操作栏存在时，消息气泡底部不再在最后一个 Markdown 块下留下多余空白。
