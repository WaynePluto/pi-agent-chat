# Pi Agent Chat 0.0.13

## 新增

- **输入框方向键回溯发送历史**：↑/↓ 回溯/前进本窗口发送过的消息。历史按窗口共享、仅存内存，上限 100 条、连续重复不入栈，保存的是用户敲入的原文与 `@` 引用 chips（会话文件存的是展开后的正文，回放拿不到原文）。导航起始时暂存草稿、回到最新时恢复；离开某个位置时把当前编辑写回该槽位，清空视为放弃。按键只在光标位于第一行/最后一行且无选区时触发——单行输入每次按键走一条，多行草稿中间的方向键留给光标移动；IME 组合中不触发，补全面板打开时补全优先，到顶/到底即停不循环。

- **打开会话时用历史用户消息预填输入回溯**：会话成为 live 时（attach 与 ready 握手，仅这两条路径；lane/preview 回放一律不灌）把当前分支的用户消息灌入 ↑/↓ 输入历史，按 transcriptId 去重，resume 后按 ↑ 即可回溯该会话的历史提问。lane 不灌是硬规则：子会话的首条「用户消息」是主代理写的任务文本，不是用户敲的。对齐 pi CLI `renderInitialMessages` 的历史填充。

- **设置菜单增加「插件设置」入口**：header 设置菜单新增「插件设置」项，打开 VS Code 设置界面并定位到 `piAgentChat` 全部设置；原「打开设置文件」更名为「编辑 Pi 全局设置文件」，语义更准确。

- **可配置消息折叠行数阈值**：新增设置 `piAgentChat.transcript.foldLines`（默认 14，即原有行为），控制长消息何时折叠为预览；设为 `0` 则永不折叠。单一阈值同时缩放行数与字符两条判定——无换行的长文本按每约 50 字符折算成一行计入同一预算。变更后重放 transcript 让已建气泡重新判定，手动开合状态与阅读位置保持不变。

## 修复

- **扩展命令后最新用户消息不再丢失操作按钮**：扩展命令（如 `/services list`）会在 transcript 中创建用户气泡但不产生 session entry，导致按位置映射的 id 索引错位，最新真实消息的气泡拿不到「回到这里 / 分叉 / 标签」按钮。扩展命令气泡现在被标记并在映射时跳过。

## 内部

- `view state` 自检新增 ready 送达的折叠阈值断言与 attach/ready 置位、lane 不置位的 `populateInputHistory` 断言；并修复其 `postState()` 未等待的竞态，使其可在无头环境运行、纳入 `pnpm verify`。
- 冒烟测试扩展输入历史（IME、草稿、编辑写回）、populate 顺序与去重、阈值 0 与恢复默认、扩展命令映射等场景，快照基线同步更新。
