# Pi Agent Chat 0.1.1

## Changed

- Model selectors (composer quick menu, full model picker, `/scoped-models`) and the composer
  model chip now show the model display name instead of the technical model id; the canonical
  `provider/modelId` reference remains available in tooltips.
- Status notices for favorite/default model changes now use the model display name.

## Dependencies

- Pi SDK (`@earendil-works/pi-ai` / `@earendil-works/pi-coding-agent`): 1.1.0 → 1.2.0.
- `marked`: 18.1.0 → 18.1.1.
- Dev dependencies: `@types/node` 24.19.1 → 24.19.2.

## Internal

- Webview smoke fixtures and snapshot baseline cover the model display name path.
- Manual retry / continue re-issues through the SDK's restructured run entry; the retry button
  keeps working after the SDK 1.2.0 upgrade.
- `dist/node_modules/` runtime set drops `@earendil-works/chord` (removed by the SDK upstream).
