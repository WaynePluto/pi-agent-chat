# Pi Agent Chat 0.0.6

## 新增

- **HTTP 代理配置**：插件现在以与 Pi CLI 相同的方式解析并安装全局 undici dispatcher。代理优先级为环境变量 → `~/.pi/agent/settings.json` 的 `httpProxy` → VS Code 的 `http.proxy`，插件既能联网也绝不会与 CLI 冲突。新增的 `httpIdleTimeoutMs` 共享设置项在改变后会重建 dispatcher。镜像的 SDK 逻辑统一用 `SDK-MIRROR:` 标记，方便后续升级时比对。
- **技能调用徽章**：显式 `/skill:<name>` 调用现在会显示独特的紫色徽章与气泡边框，在消息流中与排队、插话消息区分开来。
- **固定依赖版本**：新增 `check:dependencies` 脚本，断言所有直接依赖使用固定版本号；它已接入 `pnpm verify`，并被依赖更新技能复用。

## 改进

- **内置 Pi SDK 由 0.83.0 升级至 0.84.1**，适配了新的 `AuthInteraction` 认证流程、会话创建/切换运行时 API、模型选择器方法签名，以及全局 HTTP dispatcher。两个 Pi 包保持版本锁定、同步发布。
- 升级运行时与构建依赖：`undici` 8.8.0 → 8.10.0（单副本，仍 ≥ 8.7.0 且 ≥ SDK 自带副本）、`diff` 8.0.4 → 9.0.0、`marked` 16.4.2 → 18.0.9、`esbuild` → 0.28.2、`typescript` → 6.0.3、`@types/node` → 26.2.0。
- 新增 Husky `pre-commit` 钩子，自动清除 `pnpm-lock.yaml` 中的镜像 tarball 地址。

## 修复

- 用户消息徽章（排队 / 插话 / 技能）改为在消息右侧纵向排列，不再被长内容挤到底部。
- 技能消息在 SDK 展开技能内容后不再立即丢失排队徽章：bridge 在发送队列更新前先折叠技能调用。
- 移除了用户技能徽章中重复的技能名称。
