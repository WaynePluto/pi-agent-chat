# Pi Agent Chat 0.0.3

## 新增

- **设置菜单与 Shell 路径配置**：顶栏供应商控件改为设置菜单，收纳供应商选择、Shell 路径配置与命令帮助。可探测并选择本机常见 Shell，也支持手动输入路径；设置写入 `~/.pi/agent/settings.json`，与 Pi CLI 互通。
- 新增 `/shell-path` 与 `/help` 命令。命令帮助由内置命令目录自动生成，并随 VS Code 显示语言本地化。
- **会话管理改进**：会话列表中的重命名和删除操作固定位置显示；排队或被插话的消息可撤回到输入框；顶栏显示当前会话名称。
- 刚创建、尚未被 SDK 落盘的内存会话也会立即出现在会话列表中。
- **更丰富的模型选择器**：模型显示输入模态、上下文窗口、最大输出及思考能力；按供应商分组，并支持按供应商或能力搜索。

## 改进

- **大幅提升会话历史回放性能**：转录回放改为在 `DocumentFragment` 中构建，避免逐事件滚动，并复用空会话占位符。在 jsdom 中回放 1,000 个事件由约 6.3 秒降至 183 ms。
- 切换或新建会话会立即显示加载态，不再短暂显示上一个会话的转录。回放先于扩展绑定和资源收集执行，且会话列表刷新不再阻塞转录显示。
- 本地命令结果（如 `/session`、`/copy`）改为以默认展开的顶层转录卡片显示，不再折叠进执行过程块。
- CSS 提取共享语义变量，以及通用的折叠、chevron、pulse 和文本截断规则，视觉设计保持不变。
- 新增会话加载与回放阶段计时日志，便于定位大体量会话问题。

## 修复

- 修复角标位于首段之前时，排队或插话消息气泡顶部间距过大的问题。
- 本地命令通知不再创建运行动画永不停止的执行过程块。
- 回放仍在流式输出的会话时，不再过早关闭其活动执行过程块。
- agent 开始运行时以及新会话首条 assistant 回复完成后，都会刷新会话列表。
