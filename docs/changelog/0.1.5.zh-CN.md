# Pi Agent Chat 0.1.5

## 变更

- Anthropic 会话启用 message threads：每次请求只发送新消息，由服务端延续对话，压缩或工具清单变化时回退为整段请求。
- 符合条件的提示缓存最长保温 30 分钟（SDK 的 `cacheWarming` 默认值从 `"streaming"` 改为 `"idle"`）。

## 修复

- grep 工具的 `glob` 现在相对 `path` 匹配而不是相对工作目录；前导 `./` 不再导致零匹配。
- read 工具改为流式读取，大文件带 `offset`/`limit` 也不再内存耗尽；grep 在设置 `context` 时不再把每个匹配文件整读进内存。
- edit 工具不再重写混合 CRLF/LF 文件中未改动行的行尾，写入后也不再在大文件上内存耗尽。
- bash 工具超时的报错同时报告 shell 退出码与退出的时间。
- steering 与追加消息里的图片现在与空闲提示里的图片一样重缩放，不再以原始尺寸发送和保存。
- find 工具在 Windows 上支持 `src\**\*.ts` 这类 Windows 分隔符模式；恰好匹配 `limit` 个文件时不再误报达到上限。
- OpenAI 兼容模型在全量工具被禁用时不再发送 `"tools": []`，修复 vLLM 0.20+ 与 LiteLLM 的 400 报错。

## 升级

- Pi SDK（`@earendil-works/pi-ai` / `@earendil-works/pi-coding-agent`）：1.5.0 → 1.5.1。

## 内部

- 随包发行清单把 `grok-mermaid` 改名为 `lovely-mermaid`（SDK 1.5.1 改名）。
- 1.5.1 升级后的 SDK-MIRROR 比对：`http-dispatcher`、`builtInExtensions`、`isSyntheticPath`、自动重试两步、`/skill:` 前缀与 cli-runtime 全局变量均未变；`activity.ts` 注释里的 `cacheWarming` 默认值同步为 `"idle"`。
