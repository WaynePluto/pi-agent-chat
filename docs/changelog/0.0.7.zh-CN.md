# Pi Agent Chat 0.0.7

## 新增

- **composer 内的模型与思考等级快捷菜单**：原生 QuickPick 固定出现在窗口顶部，离被点击的 chip 太远。新增 `webview/picker.ts`，在 composer chip 正上方绘制小弹层，仅做快速切换：
  - 模型菜单只列常用模型（scoped），每行只有名称与供应商，未配置常用模型时显示「无」；末尾「其他模型…」交给原生完整 picker（搜索、能力详情、⭐常用、📌默认）。
  - 思考等级菜单列出当前模型可选等级，不加「默认」标记：SDK 的 `setThinkingLevel()` 会把所选等级直接写入 `defaultThinkingLevel`。
  - `/model`（无参数）与 `/thinking` 改为通知 webview 打开对应菜单；`ChatState.canSelectThinkingLevel` 改为 `thinkingLevels`。

## 改进

- **长会话树节点显示**：仅在真实分支处增加缩进并限制最大层级；节点标题限制为十个字符，时间移到标题行，完整消息保留在内容行并支持详情搜索。

## 修复

- **上下文压缩交互**：恢复会话时回放完整分支并展示可展开的压缩边界；压缩期间保持输入可编辑，将消息排队并在结束后继续执行；手动与自动压缩状态对齐，支持停止、撤回和双语提示。
