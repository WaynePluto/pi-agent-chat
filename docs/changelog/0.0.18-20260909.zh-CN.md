# Pi Agent Chat 0.0.18-20260909

## 新增

- 手动停止运行后，收尾提示上提供「继续」按钮；点击即恢复被停止的运行，不在对话里多出一条消息。被停止的那轮会重新发起，回答可能与停止前看到的半截不同。

## 变更

- composer 快捷模型菜单改为按供应商名、供应商内按模型名排序，不再跟随 `enabledModels` 的配置顺序；「其他模型…」原生 QuickPick 的分组不变。

## 修复

- 「上一次请求没有完成」的重试提示现在会收掉其上方的执行过程块；此前该块可能保持展开/运行样式，而提示与后续消息显示在它下方，回放会话后尤其明显。

## 内部

- 超限源码文件拆分为目录+桶结构，注释精简为中文。
- `@types/node` 对齐 VS Code 内置 Node.js 主版本。
- release 工作流对带日期后缀的 tag（如 `v0.0.18-20260909`）在 GitHub 上标记为预发布；纯版本号 tag 仍为正式发布。
