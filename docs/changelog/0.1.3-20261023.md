# Pi Agent Chat 0.1.3-20261023

## Changed

- The resource panel now counts extensions that subscribe to `agent_before_settle` or
  `cache_warming_decision` as used once a run settles.
- `models.schema.json` now includes field descriptions, so editors show hints for provider
  and model fields in `models.json`.

## Fixed

- Compaction and branch summaries no longer fail with "generation hit the token cap" on long
  reasoning; summaries use the model's output limit.
- Codemode scripts wait up to 60 seconds for a free worker instead of failing immediately;
  `PI_CODEMODE_MAX_WORKERS` raises the two-worker limit.
- The `grep` tool no longer follows `RIPGREP_CONFIG_PATH`, where user config could silently
  turn regex searches into literal ones.
- Windows shell detection finds PowerShell 7 outside `PATH` and Microsoft Store shell aliases.
- `mcp.json` files starting with a UTF-8 BOM no longer fail to parse and skip all servers.
- Automatic retry now triggers for more gateway upstream failures and transient Google Vertex
  OAuth token refresh failures.
- `/compact <instructions>` no longer ignores the instructions when summarizing the start of a
  turn that compaction splits.

## Dependencies

- Pi SDK (`@earendil-works/pi-ai` / `@earendil-works/pi-coding-agent`): 1.3.0 → 1.4.0.
- `undici`: 8.12.2 → 8.12.3.
- Dev dependencies: `sass` 1.105.1 → 1.106.1.

## Internal

- SDK-MIRROR audit after the 1.4.0 upgrade: the public export surface (`index.d.ts`) is
  byte-identical to 1.3.0 and every mirrored entry point is unchanged; the shipped-runtime
  package list gains `marked-cjk-friendly` (new bare import in pi-tui 1.4.0).
- New `extension activity` self-check drives a real `ActivityTracker` and pins the
  settle-phase companion mapping, including that `user_bash` subscribers stay unlit.
