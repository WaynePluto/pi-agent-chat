# Pi Agent Chat 0.0.18-20260909

## Changed

- The composer quick model menu now sorts entries by provider name, then by model name, instead
  of following the order of the `enabledModels` setting. The "Other models…" native QuickPick
  grouping is unchanged.

## Internal

- Oversized source files were split into directory-plus-bucket structures, and comments were
  streamlined into Chinese.
- `@types/node` is aligned with the major version of VS Code's bundled Node.js.
- The release workflow now marks date-suffixed tags (e.g. `v0.0.18-20260909`) as pre-releases on
  GitHub; plain version tags remain stable releases.
