# Pi Agent Chat 0.0.5

## Added

- **Message-level session-tree controls**: hovering a user message now exposes actions to
  return to that point, fork the session, or add a label. Returning restores the original
  prompt to the composer for retrying or resending with another model.
- **Responsive action overflow**: secondary header and composer actions move into an
  overflow menu when a narrow sidebar cannot fit them. The status line hides as a whole
  when it would be truncated.
- **Model settings and exports**: manage frequently used models, pin model ordering, and
  choose the default model independently of the current session. The shared-settings menu
  can open its configuration file directly. Session export now defaults to HTML while
  retaining JSONL export.

## Improved

- **Session browser performance**: session files are scanned only while the Sessions page
  is visible; refresh requests are coalesced. Title search and incremental scrolling keep
  large session lists responsive.
- Resource-panel sections preserve their expanded state across skill highlighting and
  resource refreshes.
- The editor background now distinguishes the chat area, and assistant messages use the
  input-area background for clearer visual hierarchy.
- VSIX packaging and installation are separate commands: use `pnpm package:vsix`,
  `pnpm install:vsix`, or `pnpm package-and-install:vsix` as needed.

## Fixed

- The composer now hides the thinking-level selector for models without selectable
  thinking levels.
- Queued-message status badges no longer squeeze short text into character-by-character
  line wrapping.
- User-message bubbles no longer leave excess space below the final Markdown block when
  their hover action bar is present.
