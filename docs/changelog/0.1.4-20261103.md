# Pi Agent Chat 0.1.4-20261103

## Changed

- Model catalog updated to models.dev v2, adding GPT-6.1 Terra for OpenAI, Azure OpenAI
  Responses, and OpenAI Codex; the default OpenAI model is now `gpt-6.1-sol`.
- Large streamed tool calls are parsed incrementally instead of re-parsing the whole argument
  string on every delta, and rendered code reuses prior highlighting.

## Fixed

- `tool_search` and codemode `searchTools()` now match Chinese, Japanese, and other non-ASCII
  queries; they previously found nothing for them.
- Resized image attachments are no longer sent as multi-megabyte PNGs when JPEG is much
  smaller; resizing picks the smaller encoding.
- Compaction and branch summaries in SDK sessions no longer pass the stored OAuth token back
  to the provider as an explicit API key.
- A failed session write no longer leaves entries in memory that are absent from disk, which
  made resumed sessions lose earlier history.
- Windows paths are compared case-insensitively, fixing skills loaded twice and project trust
  re-asked when the working and home directories differ only in drive-letter casing.
- Glob matching is hardened against denial-of-service from amplified glob patterns, and MCP
  OAuth sign-in rejects non-HTTP authorization endpoints.

## Dependencies

- Pi SDK (`@earendil-works/pi-ai` / `@earendil-works/pi-coding-agent`): 1.4.0 → 1.5.0.
- `marked`: 18.1.1 → 18.1.3.
- Dev dependencies: `@vscode/vsce` 4.0.0 → 4.1.0, `sass` 1.106.1 → 1.107.1.

## Internal

- The shipped-runtime package list gains `@earendil-works/pi-schema` (new package split out by
  the SDK in 1.5.0) and `@isaacs/nonrecursive-glob-match` (engine of minimatch 11).
- SDK-MIRROR audit after the 1.5.0 upgrade: `http-dispatcher`, `builtInExtensions`,
  `isSyntheticPath`, the auto-retry steps, the `/skill:` prefix, and the cli-runtime globals
  are all unchanged; the `ExtensionUIContext` member list is unchanged apart from a TUI-only
  `blocked` option on `custom()`.
