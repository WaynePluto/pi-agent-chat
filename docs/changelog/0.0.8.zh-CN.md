# Pi Agent Chat 0.0.8

## 新增

- **资源面板新增按需显示的 [Tools] 分区**：资源面板默认隐藏，由 header 上新增的资源按钮（位于会话树与设置之间）切换；首次显示时内部仍为折叠态，再次点击则隐藏；无资源或在会话页时按钮置灰。新增 **[Tools]** 分区列出会话注册的全部工具——扩展注册的工具可点击跳转到源文件，未激活的（如默认关闭的 `grep`/`find`/`ls`）灰显，回答「这个工具到底有没有生效」。`ResourceItem` 增加 `hint`/`inactive`，`ResourceScope` 增加 `builtin` 分组；`collectResourceSections` 改为结构化入参以便离线诊断复用，并新增 resource listing spike 校验真实会话的分区与激活状态。

- **工具行三态标记本会话调用情况**：工具行改为三态——**本会话用过**（绿色加粗）、**已激活**（正常前景色）、**已注册未激活**（说明色 + 斜体 + 半透明），各有 tooltip 说明。transcript 工具卡片创建处（实时与历史回放共用）记录被调用的工具名，与技能加载高亮走同一套机制；技能与工具共用 `resource-used` 高亮，清理原先技能专用的 `skill-active`/`active` 类名，`clearActiveSkills` 更名为 `clearResourceHighlights`。

- **扩展输出进聊天区并标记提示词/扩展的使用**：扩展的 `ctx.ui.notify` 不再弹 VS Code 通知框（单行、会截断、脱离对话），改由 `PiRuntime.setExtensionNoticeSink()` 转成 `status`/`error` 卡片写进对应 session 的 transcript，多行自动折叠；扩展命令执行期间标 `scope: "command"` 置于顶层展开，后台 notify 收进 work block 防刷屏；未接线 sink 时仍回退原生弹窗，不静默丢消息。新增 `agent/invocations.ts`：在 `prompt()` 改写文本之前解析用户输入，判定提示词模板与扩展命令的归属，回放时按无占位符的模板正文精确匹配。资源面板标记本会话用过的提示词与扩展（绿色），扩展加载失败标为 inactive（灰斜体），并去掉 GUI 不生效的 Themes 分区。同步更新 `AGENTS.md`/`ARCHITECTURE.md` 与 webview DOM 快照基线。

## 改进

- **删除 CLI 没有的 `/shell-path` 与 `/thinking` 命令**：shell 路径改由 header 设置菜单单一入口配置（`pickShellPath` 收为私有），思考等级已有 composer chip 与设置菜单入口，CLI 也早已并入 `/settings`；`openPicker` 协议收敛为仅 model，清理随之失效的 `noThinkingLevels` 文案。

## 修复

- **实时刷新模型用量状态**：每次模型响应持久化后刷新令牌、缓存和费用统计。

- **重命名非当前会话时预填原有名称**：重命名输入框此前只对当前会话回填名称，其他会话为空；现统一通过 `SessionManager.getSessionName()` 读取原名称并复用同一实例写入。
