# Pi Agent Chat 0.0.21-20261001

## Added

- The CLI's built-in extensions are now loaded: `codemode`, `tool-search` and `mcp` (bundled
  with the SDK since 0.99). They are enabled by default and can be disabled per user or
  project with `-builtin:<name>` in the shared `extensions` setting. MCP servers come from
  the shared `mcp.json` / `pi mcp` configuration; in this host `/mcp` reports its status as
  a transcript notice instead of opening a TUI screen.
- The default-tools picker in the settings menu gains `codemode`; its checked state now
  reads the parsed `defaultTools` setting, so a hand-written `+codemode` entry shows up as
  checked too.

## Changed

- The bundled model catalog follows SDK 0.99.2; new entries include GPT-6.1 Sol on OpenAI,
  Azure OpenAI and OpenAI Codex.

## Dependencies

- Pi SDK (`@earendil-works/pi-ai` / `@earendil-works/pi-coding-agent`): 0.87.1 → 0.99.2.
- `undici`: 8.11.0 → 8.11.2.

## Internal

- `runtimePackages` gains `pi-codemode`, `pi-mcp` and `quickjs-wasi` (the QuickJS sandbox
  engine behind codemode).
- The esbuild `sdkModuleUrlPlugin` now covers `pi-codemode`, backfilling a disk URL for its
  module-level `import.meta.url` so the QuickJS worker can be located; dev builds clear
  `dist/node_modules` first to prevent stale copies.
- Adapted the compaction queue to SDK 0.99 `preflightResult` semantics: the failure path is
  reported via the catch branch instead of leaving the queue's await hanging.
- New self-check for built-in extension loading: registration, `hidden` flags, and the
  codemode worker / wasm assets on disk.
- Dev dependencies: `@types/vscode` 1.99.0 → 1.99.1.
