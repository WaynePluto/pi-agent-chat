# Pi Agent Chat 0.0.1

Pi Agent Chat 的首次公开版本，基于 Pi Coding Agent 官方 SDK 的 VS Code 侧边栏聊天界面（SDK 已打包，无需 Pi CLI）。

## 新增

- 中英双语侧边栏聊天界面。
- 流式 Markdown 回复与工具执行卡片。
- 会话创建、列出、恢复、删除、树形导航、fork 与 clone。
- 模型与思考等级切换、认证、中止与追问操作。
- edit 结果的原生 VS Code diff 视图与目标文件视图。
- 内置命令、prompt 模板、扩展与技能的斜杠命令补全。
- 通过输入框 `@` 搜索的项目文件引用。
- 复用终端 Pi 在 `~/.pi/agent/` 下的配置与会话。
- 内置 Pi SDK 运行时，并为 Windows x64、Linux x64 与 macOS arm64 提供平台专用 VSIX 构建。
- GitHub Actions CI 与基于 tag 的 GitHub Release 打包。

## 说明

- 本插件为非官方社区扩展，与上游 Pi 项目及 Earendil Works 无隶属或背书关系。
- 请勿同时从插件与终端 Pi 恢复同一个会话。
- 手动上传 Marketplace 时，请使用对应 GitHub Release 中附带的平台专用 VSIX。
