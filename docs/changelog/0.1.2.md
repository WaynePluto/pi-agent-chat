# Pi Agent Chat 0.1.2

## Changed

- Switching models mid-session drops thinking blocks produced by the previous model instead of
  sending them to the new model as plain text.
- Changing the thinking level mid-session on OpenAI GPT-6 models (API key) keeps the prompt
  cache.

## Fixed

- Resumed sessions keep the tools that were activated during the session.
- Automatic retry now triggers for gateway errors "Unable to forward upstream stream" and
  "The service is temporarily unavailable".
- Tool calls whose arguments contain an invalid `\u` escape (e.g. `\usepackage`) no longer run
  silently with the fields parsed before the error; malformed JSON now fails validation and
  the model sees the raw arguments it sent.
- Repeated codemode timeouts no longer accumulate surviving QuickJS workers; at most two live
  workers are admitted across sessions.

## Dependencies

- Pi SDK (`@earendil-works/pi-ai` / `@earendil-works/pi-coding-agent`): 1.2.0 → 1.3.0.
- `undici`: 8.11.2 → 8.12.2.
- Dev dependencies: `jsdom` 30.1.2 → 30.1.3.

## Internal

- SDK-MIRROR audit after the 1.3.0 upgrade: the only `agent-session.ts` change is tool
  loadout restoration on resume; every mirrored entry point (`_startRun`,
  `_omitRecoveryAttempt`, event emits, http-dispatcher, `isSyntheticPath`, built-in extension
  list) is unchanged.
