# Pi Agent Chat 0.0.16

## Added

- New setting `piAgentChat.transcript.showThinking` (default false): while streaming, the work
  block and thinking cards stay expanded; a thinking card folds itself when its own thinking
  stream ends, and the work block folds when the block ends. Content opened or closed by hand
  is never folded automatically ([#3](https://github.com/WaynePluto/pi-agent-chat/pull/3), thanks to
  [@SimplestWay](https://github.com/SimplestWay)).

## Changed

- Collapsing a work block, card or extension widget animates over 0.22s instead of vanishing
  instantly; no animation under `prefers-reduced-motion: reduce`, older engines fall back to
  instant toggle.

## Fixed

- Streaming output without blank lines (lists, tables, dense short lines) no longer flickers
  with duplicated copies of the message text.
- Unclosed inline markers (`**`, `` ` ``, `~~`) during streaming no longer cause line-height
  jitter.

## Internal

- Headless webview smoke covers the showThinking lifecycle (expanded while streaming, folded
  at stream and block end, manual-toggle exemption); DOM snapshot baseline updated.
