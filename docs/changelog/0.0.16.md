# Pi Agent Chat 0.0.16

## Added

- Image attachments by paste: pasting a screenshot or a copied image file into the composer
  attaches it to the next message and shows a thumbnail in the conversation. Shared Pi settings
  `images.autoResize` and `images.blockImages` apply; a notice is shown before sending when the
  current model cannot read images or image input is blocked. Pasting file paths or plain text
  is unchanged, and drag-and-drop is not supported (VS Code blocks webview pointer events
  during drops).
- New setting `piAgentChat.transcript.showThinking` (default false): while streaming, the work
  block and thinking cards stay expanded; a thinking card folds itself when its own thinking
  stream ends, and the work block folds when the block ends. Content opened or closed by hand
  is never folded automatically ([#3](https://github.com/WaynePluto/pi-agent-chat/pull/3), thanks to
  [@SimplestWay](https://github.com/SimplestWay)).

## Changed

- Agent messages now carry the same backtrack / fork / bookmark actions as user messages; the
  actions sit in the outer margin next to each bubble.
- The composer's side borders align with the message column instead of extending one scrollbar
  slot wider on each side.
- The streaming caret is green, matching the agent bubble's colored edge.
- Collapsing a work block, card or extension widget animates over 0.22s instead of vanishing
  instantly; no animation under `prefers-reduced-motion: reduce`, older engines fall back to
  instant toggle.

## Fixed

- Viewing a subagent lane no longer makes the parent session lose its claim in the session
  list, and clicking the parent row no longer opens a second writer on the same session file.
- Task-line badges are now window-level facts: the whole task line stays visible in every
  session list after the parent session moves to the background.
- Session-list titles, rename prefill and the session tree no longer show raw
  `<image name="...">` markup for messages that carry image attachments.
- The subagent lane hint box no longer draws a second bottom edge over the header hairline.
- Streaming output without blank lines (lists, tables, dense short lines) no longer flickers
  with duplicated copies of the message text.
- Unclosed inline markers (`**`, `` ` ``, `~~`) during streaming no longer cause line-height
  jitter.
- Pi extensions that stream model calls through the on-disk Pi SDK copy (custom
  OpenAI-compatible providers, direct `@earendil-works/pi-ai` usage) no longer fail with
  `Cannot find package 'openai'` in packaged VSIX builds.

## Dependencies

- Pi SDK (`@earendil-works/pi-ai` / `@earendil-works/pi-coding-agent`): 0.84.3 → 0.84.4.

## Internal

- History projection and the resource-panel listing split out of `bridge.ts` into
  `agent/history.ts` and `agent/resources.ts`.
- User-message display text is projected in one place (`session-title.ts`); transcript, session
  list, header, rename, tree and queued bubbles all consume it.
- Diagnostic suites are defined once in `DIAGNOSTIC_SUITES`; new self-checks cover image
  attachments, image session titles and session ownership; the webview smoke baseline adds
  image-bubble steps.
- New `agent/jsonc-file.ts` consolidates JSONC edit boilerplate; `@types/node` 26.3.0 → 26.4.0.
- Pre-commit now verifies pinned direct dependency versions and strips registry tarball URLs
  from `pnpm-lock.yaml`.
- The unbundled runtime set under `dist/node_modules/` now ships the Pi SDK's provider SDK
  closure (`openai`, `@anthropic-ai/sdk`, `@google/genai`, `@aws-sdk/client-bedrock-runtime`
  and transitive dependencies, ~40 MB unpacked); `check_extension_runtime.mjs` imports every
  Pi SDK provider module in its sandbox, so a missing entry fails `pnpm verify`.
- `.vscodeignore` excludes `scratch/` so local scratch files never enter the VSIX.
