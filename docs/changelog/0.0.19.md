# Pi Agent Chat 0.0.19

## Added

- Working messages set by extensions via `ctx.ui.setWorkingMessage()` render in the
  status line during streaming; `setWorkingVisible()` shows or hides the row.

## Changed

- Image attachments are resized with the selected model's per-model profile
  (`inputLimits.images.resize` in models.json); coordinate-mapping hints match what the
  model actually receives.
- Manual retry and continue now omit the abandoned response from model context persistently
  (the SDK 0.87.0 mechanism); the transcript keeps showing it.
- Extensions installed behind an `index.ts` entry (npm packages and directory-style
  installs) are listed with their parent directory in the resources panel and extension
  error cards, e.g. `token-stats-timer/index.ts`.

## Fixed

- Recalling a queued or steering message with image attachments returns the images to the
  composer along with the text.
- Messages queued during context compaction now carry their image attachments to the model
  when the queue flushes.
- The pending bubble of a message queued during compaction no longer shows the raw
  `<image>` markup.
- Rewinding to, or forking from, a user message with images restores the images to the
  composer.
- Extensions no longer fail with "not a function" when calling `ctx.ui` members such as
  `setWorkingMessage()` or `setFooter()`; every member of the SDK's `ExtensionUIContext`
  is now implemented explicitly (#7).
- The first character of the streaming working-message row is no longer clipped at
  fractional pixel boundaries.

## Dependencies

- Pi SDK (`@earendil-works/pi-ai` / `@earendil-works/pi-coding-agent`): 0.85.1 → 0.87.0.
- `marked`: 18.0.11 → 18.0.13.

## Internal

- jiti is no longer bundled into `dist/extension.js`; it loads at runtime from the shipped
  `dist/node_modules/` copy, as the SDK 0.86 extension loader requires.
- The `@mariozechner/clipboard` runtime package is dropped from the shipped set; the SDK's
  native clipboard now lives inside `@earendil-works/pi-tui`. The native-clipboard spike
  probe was removed with it.
- The unbundled runtime set tracks the SDK 0.86 dependency tree: adds `proxy-agent-negotiate`,
  drops nine AWS/Smithy transitive packages and `glob`.
- Dev dependencies: `@vscode/vsce` 3.9.2 → 4.0.0, `jsdom` 30.0.1 → 30.1.0, `sass` 1.104.0 →
  1.104.1, `@types/node` 24.13.3 → 24.13.6.
- New `image resize profile` diagnostic pins that per-model resize profiles reach the
  resizer.
- New `queue recall` and `rewind attachments` diagnostics drive a real `ChatBridge` through
  queued-message recall (SDK queue and compaction queue, before and after flush),
  attachment release on consumption, and rewind image restore.
- New `extension working message` and `extension naming` diagnostics: the `ctx.ui` copy
  extensions actually receive carries every `ExtensionUIContext` member, and
  directory-named extensions list with their parent directory.
- The load smoke test exits on a timer after printing results; a locally installed
  extension that keeps timers alive no longer hangs `pnpm verify`.
