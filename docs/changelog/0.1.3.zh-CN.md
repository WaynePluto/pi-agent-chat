# Pi Agent Chat 0.1.3

## 变更

- 资源面板现在把订阅 `agent_before_settle` 或 `cache_warming_decision` 的扩展在一次运行落定后计入「本会话生效过」。
- `models.schema.json` 补齐字段描述，编辑 `models.json` 时编辑器能给出 provider 与模型字段的提示。

## 修复

- 压缩与分支摘要不再因长 reasoning 报「generation hit the token cap」；摘要改用模型自身的输出上限。
- codemode 脚本在两个 worker 都忙时最多等待 60 秒排队，不再立即失败；`PI_CODEMODE_MAX_WORKERS` 可上调默认的两个 worker。
- `grep` 工具不再跟随 `RIPGREP_CONFIG_PATH`，用户配置不会再把正则搜索静默变成字面搜索。
- Windows shell 检测能找到不在 `PATH` 里的 PowerShell 7 与 Microsoft Store 的 shell 别名。
- 以 UTF-8 BOM 开头的 `mcp.json` 不再解析失败并跳过全部服务器。
- 自动重试现在覆盖更多网关上游错误与 Google Vertex OAuth 令牌刷新的瞬时失败。
- `/compact <instructions>` 在压缩切分轮次的起始部分时不再忽略指令。

## 升级

- Pi SDK（`@earendil-works/pi-ai` / `@earendil-works/pi-coding-agent`）：1.3.0 → 1.4.0。
- `undici`：8.12.2 → 8.12.3。
- 开发依赖：`sass` 1.105.1 → 1.106.1。

## 内部

- 1.4.0 升级后的 SDK-MIRROR 比对：公开导出面（`index.d.ts`）与 1.3.0 逐字节相同，全部镜像入口未变；随包发行清单新增 `marked-cjk-friendly`（pi-tui 1.4.0 的新增裸导入）。
- 新增 `extension activity` 自检：驱动真实 `ActivityTracker`，钉住 settle 期伴随事件映射，含 `user_bash` 订阅者不点亮。
