# Pi Agent Chat 0.0.16

## 新增

- 粘贴图片附件：往输入框粘贴截图或复制的图片文件，即随下一条消息发送并在对话中显示缩略图；遵循共享 Pi 设置 `images.autoResize` 与 `images.blockImages`，当前模型不支持读图或读图被禁用时在发送前提示；粘贴文件路径与普通文本的行为不变，不支持拖拽（VS Code 在拖拽期间禁用 webview 指针事件）。
- 新设置 `piAgentChat.transcript.showThinking`（默认 false）：开启后流式期间执行过程块与思考卡保持展开；思考卡在各自思考流结束时自动折叠，执行过程块在块结束时折叠；手动点开/收起过的内容不会被自动折叠（[#3](https://github.com/WaynePluto/pi-agent-chat/pull/3)，感谢 [@SimplestWay](https://github.com/SimplestWay)）。

## 变更

- agent 消息补齐与用户消息对称的回溯 / 分叉 / 标签动作，动作条停在气泡外侧的留白里。
- 输入框左右边框与消息列对齐，不再每侧多出一个滚动条槽宽。
- 流式光标改为绿色，与 agent 气泡的彩色边框同色。
- 执行过程块、卡片、扩展 widget 的收起/展开改为 0.22s 高度过渡，不再瞬间消失；`prefers-reduced-motion: reduce` 下关闭动画，旧内核退化为瞬时切换。

## 修复

- 查看子代理 lane 不再让父会话在会话列表中交出 claim，点击父会话行不再开出同一会话文件的第二个 writer。
- 任务线徽章改为窗口级事实：父会话转入后台后，整条任务线在所有会话列表中仍可见。
- 会话列表标题、重命名预填与会话树不再显示 `<image name="...">` 原始标记。
- 子代理 lane 提示框下沿不再与 header hairline 叠出第二条边。
- 流式输出不含空行的内容（列表、表格、密集短行）不再出现正文重复渲染的闪烁。
- 流式期间未闭合的行内标记（`**`、`` ` ``、`~~`）不再引起行高抖动。
- 打包后的 VSIX 中，经磁盘 Pi SDK 做模型调用的 pi 扩展（自定义 OpenAI 兼容供应商、直接使用 `@earendil-works/pi-ai`）不再报 `Cannot find package 'openai'`。

## 升级

- Pi SDK（`@earendil-works/pi-ai` / `@earendil-works/pi-coding-agent`）：0.84.3 → 0.84.4。

## 内部

- 历史投影与资源面板清单从 `bridge.ts` 拆出为 `agent/history.ts` 与 `agent/resources.ts`。
- 用户消息显示文本统一由 `session-title.ts` 投影，transcript、会话列表、header、重命名、会话树与排队气泡全部消费它。
- 自检清单单一化为 `DIAGNOSTIC_SUITES`；新增图片附件、图片会话标题与会话归属自检；webview 冒烟基线新增图片气泡步骤。
- 新增 `agent/jsonc-file.ts` 收敛 JSONC 编辑样板；`@types/node` 26.3.0 → 26.4.0。
- pre-commit 改为校验直接依赖精确版本，并通用化 `pnpm-lock.yaml` 的 tarball URL 清理。
- `dist/node_modules/` 随包运行时集补齐 Pi SDK 的 provider SDK 闭包（`openai`、`@anthropic-ai/sdk`、`@google/genai`、`@aws-sdk/client-bedrock-runtime` 及传递依赖，未压缩约 40 MB）；`check_extension_runtime.mjs` 在沙箱逐个 import Pi SDK 的 provider 模块，缺包直接令 `pnpm verify` 失败。
- `.vscodeignore` 排除 `scratch/`，本地临时文件不再可能进入 VSIX。
